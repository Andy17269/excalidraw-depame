# 购物与科技 UI 视觉素材

2026-11-15，使用内置 image_gen 逐张生成，共 20 张（购物 10、科技 10）。最终提示词保存在 prompts.json，原始 PNG 的本机路径保存在该文件中。运行时使用项目内的 WebP，不需要在线生成或远程图片服务。

打开 preview.html 可浏览全部素材。购物位于 public/ui-assets/shopping，科技位于 public/ui-assets/technology。src/services/uiPlaceholderAssets.ts 保存元数据，并由 uiAssets.ts 并入现有查询目录。

- 方图 16 张：640×640，适合商品卡、分类入口、推荐列表和功能卡配图；文字放在图片外。
- 横幅 4 张：宽 960px、接近 16:9，主体在右侧，左侧供独立标题使用；保持原比例，裁切后重新核对安全区。
- 图内不放商品名、价格、按钮、运营数据；这些应继续使用可编辑文字与图形。
- 标签支持“购物”“科技”，运行时仍沿用 media/hero 两种既有组件用途分类。

## 对齐用户指定的成图标准

以现有音乐 App、旅行发现 App、电商运营工作台为视觉质量参考。完整页面应保持草图的主要区域和比例、统一主题、清晰文字层级、完整导航与内容区。新素材提供图像内容；标题、商品信息、按钮、图表和表格由组件布局负责。

购物页面建议：精选横幅 + 分类导航 + 双列商品卡 + 价格与操作；科技页面建议：主题横幅 + 功能入口 + 设备或能力卡 + 状态信息。页面中的一张大图和少量次级图应形成视觉重点，避免堆满素材。

本批素材已接入目录，完整流式布局方案见 docs/ui-sketch-streaming-solution.md。
