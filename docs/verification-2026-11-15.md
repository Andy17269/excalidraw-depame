## 本轮修复

1. **启动主按钮对比度**：移除局部白字覆盖，沿用品牌蓝与全局 `--on-action`。修复前实测 3.12:1；修复后原生对比度测试通过。
2. **AI 连接配置入口**：恢复地址、模型与密码型 API Key 输入。提交后清空密钥输入，设置查询不回传原文，新安装可配置自己的服务。
3. **语音错误污染文件状态**：麦克风/ASR 失败改为语音提示，文件状态不再错误地变成保存失败。权限拒绝测试先复现、再验证修复。
4. **视觉结果覆盖新修改**：在异步处理各阶段校验源元素版本。延迟结果覆盖测试修复前失败，修复后三种竞态回归通过。
5. **源码共享凭据**：移除源码内嵌 API Key，迁移至既有本机设置和忽略的 `.env.local`。发布文件树与重新生成的发布包已检查，不包含迁移出的凭据。
6. **开发服务误重载**：Vite watcher 排除隔离测试、构建和宣传产物目录，避免测试创建 HTML 文件触发应用重载。
7. **过期测试脚本**：更新旧 Welcome 文案、已迁移的菜单/设置入口、重复隐藏面板选择器与演示模式离线规则；不修改产品行为来迎合旧断言。

增加 `npm run test:native` 串行运行器、`npm run test:browser` 自带隔离服务，以及延迟 AI、文件异常、发布包迁移、手动编辑和 Demo 文件测试。运行器对失败保留日志，对不支持的项目明确输出 SKIP。

## 实测边界与剩余事项

- **原生减少动态效果**：当前 SDK 的 `Emulation` 类型和 MCP 工具 schema 只提供 colorScheme。旧脚本的 reducedMotion 参数被运行时忽略；本轮不将其算作原生通过，改在真实 Chrome 的 reduce 媒体查询下验证欢迎、引导与开关。
- **外部画布 MCP 的安装边界**：开发会话 stdio 链路已验证；脱离源码目录的安装包不带 stdio 桥接脚本与 Node 依赖，仍需保留源码和 acde dev。安装包不是独立注册的桌面 `canvas` 服务。当前文档已移除旧版不存在的服务路径。
- **真实硬件**：没有人工操作物理 Fn、真实麦克风权限面板、真实触摸板手感或观察系统通知横幅。软件事件、合成媒体和接口协议通过不能替代这些项目。
- **依赖告警**：`npm audit --omit=dev` 返回 12 项关联依赖告警：9 high、1 moderate、2 low、0 critical。npm 建议包含 Excalidraw 降级或 Mermaid 跨主版本变更；本次没有执行强制升级/降级，也没有宣称安全审计通过。明细留在本地 dependency-audit.json。
- **功能范围**：当前主菜单没有完整 PNG/PDF 导出面板，AI 结构编辑仍以追加和文字/颜色修改为主；自动恢复的文档身份、同名最近文件以及恢复备份的可见入口仍可继续完善。本轮没有把这些待开发能力算作已实现或测试通过。
- **凭据历史**：旧本地分支仍包含历史凭据，保留但未上传。应更换旧凭据；不要直接推送旧历史。干净发布分支独立建立，没有改写原分支。
