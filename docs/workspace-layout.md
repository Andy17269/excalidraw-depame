# 工作区与发布包边界

整理日期：2026-11-15。保留所有本地文件，不删除真实白板或原始设计资料。

| 目录 | 用途 | Git 与运行包策略 |
| --- | --- | --- |
| `src/`、`server/`、`scripts/` | 应用实现、构建与测试工具 | 版本管理；由构建器按入口收集依赖 |
| `public/` | 离线字体、HEIC worker、UI 素材及示例照片 | 必须版本管理，随运行包分发 |
| `tests/` | 单元、原生、浏览器与显式真实接口测试 | 版本管理；测试结果不随源码提交 |
| `docs/` | 设计说明、接入文档、精选预览与验证记录 | 版本管理；不会进入 acde 运行包 |
| `demo/boards/`、`demo/guide/` | 已准备的可编辑示例白板和使用说明 | 保留可交付示例与配套截图，不随应用运行包分发 |
| `demo/demo/`、`demo/banner.af` | 原始导入资料及设计源稿 | 保留本地，忽略提交 |
| `marketing/` | 宣传片脚本、卖点、字幕与采集脚本 | 保留文本与脚本；MP4、ZIP、PNG/JPG 导出留在本地 |
| `promo-video/` | 可编辑宣传片工程 | 保留 HTML/CSS/JS、固定依赖与制作输入；音轨和评审帧可再生成，忽略提交 |
| `.debug/` | 隔离 profile、日志、截图、干净检出及验证发布包 | 全部忽略；不要复制进 `public/` |
| `.acde/`、`dist/` | 本机构建输出 | 全部忽略，按需要单独分发 |
| `.env.local` | 本机真实接口测试配置 | 忽略提交；`.env.example` 仅包含空值和公共默认地址 |

运行包实测只包含 `package.json`、`backend/` 与 `web/` 等构建器产物。宣传成片、原始设计文件和测试 profile 没有混入运行包；不需要移动或删除源工程来缩小应用包。

## 再生成与检查

- 前端与 HEIC/font 资源：`npm run build`。
- 原生应用：`acde build`，或用 `--out` 指定交付目录。
- 应用功能：`npm test`、`npm run test:browser`、`npm run test:native`。
- 宣传片音轨：在 `promo-video/` 中运行 `node make-music.mjs`，再按该目录 README 预览或渲染；本次仅整理其源文件，没有重制视频。
- 原生回归日志与截图：查看运行器最后输出的 `output` 路径。报告引用的是当前验证结果，不把旧的静态审查文件当作新一轮测试。

发布分支 `codex/verified-native-20261115` 从已检查的当前文件树建立独立历史；不包含旧的敏感提交。API 凭据迁移到本机设置和被忽略的 `.env.local`，没有复制到文档、测试报告或新发布分支。旧凭据仍应由持有人更换。

不使用强制推送，不重写原分支，不删除未纳入版本管理的原始文件。视频和压缩包留在本机，GitHub 保留可重新生成它们的源文件。
