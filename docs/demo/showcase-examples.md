# 三套固定展示示例

设置 → 通用 → 演示模式。开始页（无历史文件时）、空画布推荐或底部「预设模板」均可插入：

1. **音乐 App**：首页推荐、专辑封面、播放控制与底部导航。
2. **旅行发现 App**：搜索和分类、海岸目的地大图、周末路线卡；本地打包摄影素材。
3. **电商运营工作台**：四项经营指标、七日成交趋势、渠道占比与最近订单。

插入后点「UI草图」→「整页生成」。多个示例同在画布时，框选其中一套再点击「生成选中区域 UI」。支持继续编辑和单步撤销。三个案例都可断网展示，普通 AI 请求仍需联网。

这些是内置精选示例：草图和结果对应同一组主要区域，展示布局完善、素材填充、可编辑图形与绘制动画，不代表每次在线模型都能生成完全相同的结果。应用只对入口插入的完整示例启用固定结果；普通用户草图不因关键词而替换为示例。

如果复制了一套草图，请通过示例入口重新插入一套再生成，以避免两个复制件共享标记。旋转后的外框需要先回正。

运营数据为示例：七天成交额 12,600 + 16,400 + 15,200 + 19,800 + 17,400 + 24,800 + 22,440 = 128,640；1,248 单对应客单价约 103.08。渠道占比 48% + 32% + 20% = 100%。

图片来源和许可见 `public/showcase-assets/README.md`。
