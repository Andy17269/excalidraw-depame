先打开 `boards/` 里的任意一个 `.excalidraw` 文件。三个文件已经放好内容，不用输入提示词、不用等模型生成。

| [02 · 旅行发现 App](boards/02-旅行发现App.excalidraw) | 目的地大图、分类、周末路线；草图与完成界面对照 | [看图](previews/02-旅行发现App.png) |

旁边的箭头、说明和下划线也是白板元素，可以选中、移动或删除。界面中的文字、卡片和图表可继续编辑；照片和封面已嵌入文件。

## 怎么打开

1. 启动本项目的 Excalidraw+。
2. 左上角「菜单 → 打开…」，选择一个 `.excalidraw` 文件；首次引导完成后的开始页也能打开文件。
3. 打开后会自动适配整张白板。想看细节就放大，不用重新生成。
4. 建议通过「另存为…」保存自己的演示副本，再随意改。

标准 Excalidraw 也能导入这三个文件；本目录的操作截图按当前 Dopame 应用整理。
