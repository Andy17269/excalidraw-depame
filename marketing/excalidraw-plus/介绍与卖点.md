## 六个核心卖点

### 说出想法，看见结构。
描述你想表达的内容，让 AI 帮你绘制流程图、架构图与思维导图。复杂关系，逐步清晰。

### 几笔草图，下一步的样子。
把手绘线框交给 AI，生成更完整的界面设计。支持选区或整页处理，让草图成为设计的起点。

### 想改哪里，就说哪里。
按住语音按钮，说出你的想法。将口头表达转成画布指令，在已有内容上继续调整。

### 生成之后，创作继续。
图形、文字与连线留在画布上。继续移动、修改、组合，让每一次生成成为下一次创作的开始。

### 给智能体，一张共同的画布。
通过 MCP，让兼容的 AI 客户端读取画布摘要、追加图表。也能接入外部 MCP 工具，为创作带来更多上下文。

### 灵感在流动，作品有着落。
本地文件、自动保存与快照管理，衔接每一次创作。搭配浅色与深色外观，让画布自然融入你的桌面。

## 功能依据与表达边界（内部使用）

以上文案对照当前工作区 README 与实现整理，2026-11-15。

| 主张 | 代码依据 | 使用边界 |
| --- | --- | --- |
| 文字绘图 | src/services/canvasBridge.ts、src/App.tsx | AI 配置与网络可用时；不同图表类型编辑能力取决于转换器 |
| 草图生成 UI | src/services/aiVision.ts、server/visionUi.ts | 生成质量取决于输入和模型 |
| 语音修改 | src/useVoiceInput.ts、src/services/canvasPlan.ts | 需要麦克风权限、语音识别与 AI 服务；不宣传离线语音 |
| 持续编辑 | canvasBridge.ts、aiVision.ts | 原生图形和文字可编辑；图片素材并非内部每个像素/组件都可编辑 |
| MCP | scripts/canvas-mcp.mjs、server/mcpManager.ts | 需配置兼容客户端/服务；不等同于多人实时协作 |
| 本地文件与快照 | src/services/excalidrawStorage.ts、src/useCanvasDocument.ts | 本地存储不代表 AI 请求不会发送内容；不宣传“所有数据不出设备” |
| 深浅外观 | src/services/theme.ts、src/theme.css | 跟随系统或手动选择 |
